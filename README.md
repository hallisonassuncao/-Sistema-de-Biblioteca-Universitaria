# ✔ Aplicação em Python, estruturada segundo o padrão de arquitetura MVC (Model–View–Controller) e utilizando orientação a objetos, para gerenciar um pequeno sistema de biblioteca universitária. O programa utiliza um banco de dados PostgreSQL com duas tabelas relacionadas. Uma tabela autor com id, nome e nacionalidade e outra tabela livro com id, título, ano de publicação e o id do autor do livro.  - Atividade Avaliativa 3 - Módulos 3 e 5 - Instituto Federal de Brasília (IFB)
